# Assets

Two kinds of files are built into this folder, under different licenses:

- **Game data**: `gamedata.json` and `datapack/`, under MPL-2.0. These are derived from Cobblemon's data files: species stats, learnsets, level evolutions, catch rates, growth curves and grounded spawn entries from `data/cobblemon/species` and `spawn_pool_world`; English move, ability and type names from `assets/cobblemon/lang/en_us.json`; and Cobblemon's biome tags, copied unchanged into a datapack. They are generated by `tools/build_data.py`.
- **Models, animations and textures**: CC BY-NC 3.0, described below.

## Models, animations and textures

The model, animation and texture files built into this folder (`java/`, `bedrock/`) are **adapted from [Cobblemon](https://gitlab.com/cable-mc/cobblemon)**, taken from the commit in [`../COBBLEMON_COMMIT`](../COBBLEMON_COMMIT) (`common/src/main/resources/assets/cobblemon/...`). ## Changes made

For each species, the base-form model, texture and poser are taken from Cobblemon's resolver (order 0, no aspects).

| Output | Changes |
|---|---|
| `java/<species>.bbmodel` | Converted to Blockbench `.bbmodel` by `tools/geo2bb.py`. The X axis is mirrored for Blockbench, and box UVs are expanded to per-face UVs. Geometry and position keyframes are multiplied by the species `baseScale`. Molang expressions are baked to keyframes at 20 per second; riding, sound and variable queries are treated as 0. Channels that can't be evaluated are dropped and counted in `species.tsv`. The texture is embedded unchanged. |
| `bedrock/<species>/*.geo.json` | The geometry identifier is renamed to `geometry.<species>`. When `baseScale` ≠ 1, a `cl_scale` root bone is added. |
| `bedrock/<species>/*.animation.json` | Only the idle and walk animations are kept, renamed `idle` and `walk`. Sounds, particles and timelines are removed. Cobblemon-only queries are replaced by 0, and every animation scales the `cl_scale` bone to `baseScale`. |
| `bedrock/<species>/*.png` | Unchanged. |

All other animations, forms, shiny textures and emissive layers are dropped.

### Repairs to Cobblemon's animation data

Applied to both the Java and Bedrock outputs:

- **Decimal commas.** `4,46` outside a function call is read as `4.46`. Grafaiai's `hair2` bone has `...*4,46`, and its sibling `hair` bone has `...*4.46`.
- **Bare names become 0.** This covers `NaN` (an export artifact in 15 species, such as Milotic and Incineroar) and Clamperl's undefined `speed`. Molang itself evaluates unknown names to 0, so the result matches the mod.

**Left as-is.** These are real typos with no single obvious fix: Cyndaquil (unbalanced parentheses), Togetic (`-0.0.5`) and Ursaluna (`0.532.5`). Each drops 2 Java channels, and Bedrock gets the original text.
